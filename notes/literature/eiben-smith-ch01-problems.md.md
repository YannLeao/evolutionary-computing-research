# Problems to be Solved  
  
**Source:** Introduction to Evolutionary Computing — Eiben & Smith  
**Chapter:** 1 — Problems to be Solved

## Overview  
  
This chapter introduces different classes of problems that evolutionary computing aims to solve, particularly optimisation, modelling, and simulation problems.  
It highlights that many of these problems can be framed as search problems, where the goal is to find a suitable solution within a large space of possibilities.

## Main Ideas
### Search Perspective  
Many of these problems can be interpreted as **search problems**, since solving them requires identifying one or more suitable solutions within a space of possibilities.  
  
In optimisation, this means finding the best solution.  
In modelling, it means finding a model that accurately represents the system being studied.
