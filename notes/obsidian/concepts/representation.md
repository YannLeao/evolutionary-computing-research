# Representation (Evolutionary Algorithms)

## Definition
Representation is used in two slightly different ways. Sometimes it stands for the mapping from the[[ phenotypes]] to the [[genotypes]] space called **encoding**.
The inverse mapping from genotypes to phenotypes is usually called **decoding**.

## Example
Given an optimisation problem where the possible solutions are integers, the given set of integers would form the set of phenotypes.
In this case one could decide to represent them by their binary code, we have:
- 18        **phenotype**
- 10010  **genotype**
